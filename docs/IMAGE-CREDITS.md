## Brand assets

`public/brand/` and the app icons (`app/icon.png`, `app/apple-icon.png`, `app/favicon.ico`) are generated from the
official logo (`assets/brand/plumbon24-logo-original.jpeg`) by `npm run brand:assets`. The logo is never redrawn:
the script only removes the white background, trims the margins and crops the faucet + water drop for small icons.
